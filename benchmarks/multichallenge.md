## What It Tests
Whether a model holds a **conversation** together over many turns, not just answers one prompt well.
It targets four skills that require instruction-following, context allocation, and in-context
reasoning simultaneously:

- **Instruction Retention** — keep obeying an instruction set early, even when later turns tempt a drift.
- **Inference Memory of User Information** — infer and reuse facts the user stated earlier (a stated allergy, a preference).
- **Reliable Versioned Editing** — track content state across revisions, including reverts and conflicting edits.
- **Self-Coherence** — avoid contradicting the model's own earlier statements.

## How It Scores
**Accuracy**: the share of the 273 conversations the model passes.

- **Instance-level rubric** — one human-written yes/no question per conversation.
- **LLM judge** — answers that question from the final response alone.

## Format
Multi-turn conversations averaging **5 turns** and about 1,232 words: 113 inference memory, 69 instruction retention, 41 reliable version editing and 50 self-coherence. They were generated synthetically and then reviewed and edited by human experts. Only the final model turn is judged.

## Limitations
- **Judge-dependent.** The judge model and rubric wording affect the score.
- **Partial coverage.** Four categories of conversational failure, not all of them.

## Example
The paper's inference-memory example: a user mentions nut allergies early on and later asks for dessert recipes without restating them. The rubric question is "does any of the dessert recipes suggested in this response contain any nuts?"; a response with nuts fails.
